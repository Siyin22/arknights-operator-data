# 明日方舟 · 干员版本数据

当前官方数据版本：**78.2.0**（国服）。

[阅读本次更新报告](更新报告.md) · [查看所有官方版本](https://github.com/Siyin22/arknights-operator-data/tags)

只保存干员与模组的可读战斗数据。根目录始终是一套当前数据；旧版本保存在 Git 历史中，不按日期重复复制整套导出。

| 内容 | 说明 |
| --- | --- |
| `operators/` | 每名干员一个 JSON，含职业形态；最高精英阶段、满级、满信赖，各潜能属性、天赋、技能七级及专精 |
| `modules/` | 每个模组一个 JSON，含所属干员、各级属性与天赋/特性效果 |
| `version.json` | 官方 VersionControl 数据版本与官方资源版本标识 |
| `更新报告.md` | 与上一已保存版本对比的新增、修改和移除；GitHub 可直接阅读 |
| `更新报告.html` | 下载后离线阅读，新增详情可切换潜能 |
| `compare.py` | 只需 Python 标准库，比较任意两个已保存版本 |

当前包含 434 个干员 / 职业形态、503 个模组。

## 版本对比

GitHub 顶部的标签选择器可浏览指定版本，也可使用 Compare 查看两个标签的文件差异。

克隆仓库后运行（把两个版本替换为仓库中已有标签）：

```sh
python compare.py <旧官方版本> <新官方版本>
```

生成 `comparison/版本差异.html` 与 `comparison/版本差异.md`；不会改动当前数据。

已保存版本：[78.2.0](https://github.com/Siyin22/arknights-operator-data/tree/78.2.0)

## 数据口径

版本号直接读取游戏 `data_version.txt` 的 `VersionControl`，不是工具版本或导出日期。
技能描述已经代入参数。属性不叠加模组和战斗中的天赋、技能增益；模组各级加成不累计。
基于客户端可获取标记筛选干员；职业形态分别记录；默认职业证章不计作模组。
对比范围是已保存版本之间的变化，首次保存仅建立基准。

游戏数据与文本的相关权利归原权利人；本仓库为非官方的个人数据对照记录。
