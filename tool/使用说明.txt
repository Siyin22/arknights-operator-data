明日方舟 · 干员版本对比

怎么用
1. 等游戏更新完成，双击“启动工具.vbs”；打不开时用“启动工具.cmd”。
2. 确认游戏目录，点击“提取并上传 GitHub”。注意：这个按钮会上传到公开仓库。
3. 点击“查看报告 / 导出图片”，查看本次新增、修改、移除的干员和模组。
4. 比较历史版本：选择两个已保存的数据版本，点击“查看版本差异”。

怎么导出图片
本次新增干员默认勾选本次新增的所属模组；“导出本次资料”将它们合并成图，不重复导出已合并模组。老干员的新模组单独成图；取消勾选的模组恢复单独导出。
报告默认使用潜能 1；如有需要可切换潜能和技能等级，再点击卡片上的导出按钮。
干员卡片的“所属模组”可勾选一起展示，点击“合并导出 PNG”生成干员加所选模组的长图。
点击“仅干员 PNG”可只导出干员；模组旁的“模组对比 PNG”可单独导出该模组。
模组单图包含同一数据版本、同一潜能的无模组特性与天赋，便于对照各级效果。
文字下半部的淡红色标记表示同一模组效果相较上一级新增或改写的文字，片段首尾的分隔标点不标记，原始完整描述仍保留。
需要多张时，把干员或模组加入清单后批量导出 ZIP，每项独立一张图片。
清单保留加入时勾选的模组；导出时使用页面顶部的潜能和技能选项。
更新报告按所属干员归组，每项分别标记新增、修改或移除；对照资料不计入更新统计。
文件保存在浏览器下载目录。已有干员、模组也能搜索后导出。
长图过长时，可减少勾选模组，或将技能切换为最高等级，再分别导出。

界面、报告与导出图片优先使用本机“霞鹜文楷”，缺少时使用“微软雅黑”。

数据说明
干员采用满级、满信赖属性，保留各潜能、技能七级及专精、后勤技能和模组各级效果。
后勤技能显示满级已解锁的最终效果、设施和解锁条件，同组升级不重复叠加。
客户端版本（如 2.7.81）与数据版本（如 78.2.0）不同；历史对比使用数据版本。
首次提取只建立基准；以后才能判断新增内容。同版本重复运行不会重复保存。

文件在哪里
GitHub 版：仓库根目录是当前数据、离线报告和 Git 历史，tool 目录是工具。
原本地布局：版本数据文件夹保存当前数据、报告和 Git 历史。请保留仓库中的隐藏 .git 文件夹。
work：临时文件和手动比较结果；提取成功后自动清理提取中间文件。
src、tools、adapters、.venv：程序和运行依赖，请一起保留。

遇到问题
上传失败：点击“重试上传”，不用重新提取。
提取失败：保留 work/提取临时/诊断包.zip，供排查。
只看已有资料：打开仓库根目录的“更新报告.html”；原本地布局则打开“版本数据/更新报告.html”，无需提取或上传。
