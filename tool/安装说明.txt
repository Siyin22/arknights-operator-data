明日方舟更新工具 · 首次安装（Windows x64）

1. 安装 Python 3.12 x64（包含 Tk）、.NET 8 运行时、Git 和 GitHub CLI。
2. 克隆完整仓库以保留版本历史：
   git clone https://github.com/Siyin22/arknights-update-tool.git
   cd arknights-update-tool\tool
3. 在 tool 目录创建 Python 环境并安装依赖：
   py -3.12 -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements-lock.txt
4. 如果要上传，请先用 gh auth login 登录有仓库写权限的账号。
5. 双击 tool 目录中的“启动工具.vbs”，或使用“启动工具.cmd”。

tool 目录已包含提取所需的适配解析器、flatc、Capstone 与原许可证。
工具识别 tool 上一级的 Git 仓库，直接读取和维护根目录的版本数据，不会另建一份仓库。
当前本地旧布局仍兼容：工具根目录下的“版本数据”也可作为独立 Git 仓库使用。
不要复制现有 .venv 到其他机器；请按步骤创建环境。

查看现有报告只需 Chrome/Edge 打开仓库根目录“更新报告.html”，不需要上述运行环境。
提取要求本机国服 PC 客户端，当前支持客户端 2.7.81；客户端升级后需核实适配。
界面优先使用已安装的“霞鹜文楷”，未安装时使用微软雅黑。
“提取并上传 GitHub”会将生成的数据与报告推送到上述公开仓库。

网络请求仅在对应子进程使用本地 127.0.0.1:7897 代理，不修改全局代理。
安装 Python 依赖时可自行选择可用的国内镜像，或在该次 pip 命令加 --proxy http://127.0.0.1:7897。
